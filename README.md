# Marce

I build small, self-hosted tools and run them myself.

**[ActualBudget-Overview-Dash](https://github.com/TrasteCC/ActualBudget-Overview-Dash)** is a single-container dashboard for [Actual Budget](https://actualbudget.org): monthly KPIs, a 12-month summary, spending by category and tag, and an editable transaction list. It talks to your actual-server directly, no extra database or API layer.

Try it at [actual-dash.marcecastro.com](https://actual-dash.marcecastro.com) with made-up data.
